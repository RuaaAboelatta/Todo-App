## Features 🚀

- ✅ **Full CRUD** - Create, check, delete, and clear todos
- 🌓 **Theme Switching** - Toggle between light/dark modes with smooth transitions
- 🔄 **Drag & Drop** - Reorder tasks by dragging (works on mobile too!)
- 🔍 **Smart Filtering** - View All, Active, or Completed tasks
- 📱 **Fully Responsive** - Optimized for desktop, tablet, and mobile
- 🎨 **Custom Design** - Gradient checkboxes, hover effects, styled scrollbar

## Built With 🛠️

- **React** - Hooks (useState, useEffect, Custom Hooks)
- **CSS3** - Variables, Flexbox, Media Queries, Transitions
- **[@spfxappdev/sortable](https://www.npmjs.com/package/@spfxappdev/sortable)** - Drag-and-drop library

## Responsive Breakpoints 📱

- **Desktop:** > 960px
- **Mobile:** < 960px (optimized for 375px)

## Usage 💡

| Action | How To |
|--------|--------|
| **Add todo** | Type and press Enter |
| **Complete todo** | Click the circle |
| **Delete todo** | Hover and click cross |
| **Reorder** | Drag any todo |
| **Filter** | Click All/Active/Completed |
| **Toggle theme** | Click sun/moon icon |
